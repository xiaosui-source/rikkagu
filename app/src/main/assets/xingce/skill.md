# 花生十三行测解题方法论

## 总纲
- 流程：识别题型→调用方法→列式计算→校验易错点
- 资料分析：重口径审题（基期/现期、同比/环比）与速算（截位直除/份数法）
- 数量关系：重代入排除与方程，善用整除/奇偶/尾数特性

## 资料分析
### 基础知识
- **资料分析基础术语与审题四步**｜圈出主体和关键词，确认增长率、增长量、比重、平均数等指标类别｜〔倍数 = 增长率 + 1;人口自然增长率 = 人口出生率 - 人口死亡率;翻n番 = 原来的2^n倍〕｜⚠把产业增加值误当成增长量
- **统计术语与常识基础**｜2. 根据术语的定义或转化公式，将术语转化为常规的数学关系表述｜〔倍数 = 增长率 + 1;翻n番为原来的 2^n 倍;进出口 = 进口 + 出口〕｜⚠将增加值等同于增长量

### 基期量
- **基期量直接公式法**｜增长为正时用A=B/(1+R)，下降为负时用A=B/(1-R的绝对值)｜〔A = B / (1 + R);X = B - A = B - B/(1+R);也可记为：A = B - X = X/R〕｜⚠把现期量B误当基期量A
- **隔年前期先求间隔增长率法**｜若R间接近常用分数，可用415份数法或假设分配法估算｜〔R间 = R1 + R2 + R1×R2;A隔年 = B / (1 + R间)〕｜⚠遗漏R1×R2项
- **前期差值比较法**｜分别识别两个对象的现期量B1、B2及增长率R1、R2｜〔A1 - A2 = B1/(1+R1) - B2/(1+R2)〕｜⚠直接用现期差替代前期差

### 现期量
- **现期量列式与假设增量法**｜若未来保持增长量不变，先设X并列出‘当年量+n年增长量X’的不等式或方程｜〔B = A × (1 + R);B = A + X〕｜⚠保持增长量与保持增长率混淆

### 增长率
- **一般增长率公式法**｜选项差距大时截位直除，差距小时保留足够有效位｜〔R = X / A = (B - A) / A〕｜⚠把增长量X除以现期量B
- **间隔增长率及逆运用**｜逆向题：由R间-R已知项，再考虑乘积项方向，必要时比较选项｜〔R间 = R1 + R2 + R1×R2;逆向：R1 = (R间 - R2)/(1 + R2)〕｜⚠只加不乘，尤其当选项接近时容易错
- **比值增长率公式法**｜若问平均数增长率，记住‘均前每后’：平均、每后面的量通常作分母｜〔Ra = (Rb - Rc) / (1 + Rc);当只判断升降：Rb > Rc则比值上升，Rb < Rc则比值下降〕｜⚠把比值增长率误当比重差，选百分点
- **乘积增长率公式法**｜代入Ra=Rb+Rc+RbRc；若增长率较小可先估算Rb+Rc，再校验乘积项｜〔Ra = Rb + Rc + Rb×Rc〕｜⚠漏掉Rb×Rc

### 增长量
- **增长量公式与方法选择**｜若A和R明确，用X=A×R；若B和R明确，用X=B×R/(1+R)｜〔X = B - A = A×R;X = B×R/(1+R);R≤5%且粗略判断时：X≈B×R〕｜⚠用B×R作为精确增长量，忽略分母
- **B-R双大与N倍比较法**｜若B一大一小、R一大一小，判断‘我的B是你的几倍，你的R是否是我的几倍以上’；只有双方倍数相当才可能相等｜〔X = B×R/(1+R);B大且R大 => X大；若B大R小，要比较B倍数与R倍数〕｜⚠只看增长率高低，不看基数大小

### 比重
- **本期比重主体定位法**｜先判断谁是主体、谁是整体，避免分子分母倒置｜〔本期比重 = 部分 / 整体;多部分比重 = 部分和 / 整体〕｜⚠分子分母反了
- **基期比重公式法**｜代入现期比重×(1+R整体)/(1+R部分)｜〔基期比重 = 现期比重 × (1 + R整体)/(1 + R部分);即：a/b = (A/B) × (1+R整体)/(1+R部分)〕｜⚠把R整体和R部分的位置写反

### 比重变化
- **比重趋势比较增速法**｜R部分>R整体，则比重上升；R部分<R整体，则比重下降；相等则不变｜〔R部分 > R整体 => 比重上升;R部分 < R整体 => 比重下降〕｜⚠把比重上升误认为增长量更大
- **比重差公式与秒杀法**｜需要数值时，用基期部分/本期整体或现期部分/整体的近似比重乘以增速差｜〔比重差 = 本期比重 - 基期比重;近似/公式框架：比重差 ≈ (基期部分/本期整体) × (R部分 - R整体);秒杀：|比重差| < |R部分 - R整体|〕｜⚠把百分点写成百分比增长率
- **三类分式变化辨析表**｜看问法：‘平均...增长率’多为比值增长率；‘占...比重’一定优先归比重类｜〔比值增长率：Ra=(Rb-Rc)/(1+Rc);比重差：A/B-a/b，单位百分点或%;比值差：A/B-a/b，单位有实际含义，不可用比重差秒杀〕｜⚠看到分式就全部套比重差

### 平均数
- **一般平均值‘均前每后’法**｜若为平年/闰年题，注意能否被400整除或能被4整除但不能被100整除｜〔平均数 = 总量 / 份数;A/B ÷ C/D = AD/BC〕｜⚠分母找错，尤其‘平均每’结构
- **年均增长量基期判断法**｜图表有第一年问题从第二年问起时，基期往前推；若直接从图里第一年问起，通常不用推｜〔年均增长量 = (末期量 - 基期量) / 年份差n〕｜⚠直接把题面起始年份当基期，忽略前
- **年均增长率幂次与近似法**｜记忆常见幂：1.05^4≈1.216，1.1^4≈1.46，1.15^4≈1.75，1.2^4≈2.07｜〔(1 + R)^n = 末期 / 基期;末期/基期 ≈ 1 + nR（粗略近似）〕｜⚠把年均增长率当成(末期-基期)/
- **一般平均值法则与技巧**｜如果是除法算式可先转换形式约分｜〔(A/B) ÷ (C/D) = (A×D) / (B×C)〕｜⚠分子分母搞反

### 比较类
- **双线法与比值趋势法**｜用双线法画出分子与分母趋势：若分母持续上升、分子下降，则分数变小；反之变大｜〔分子增长率 > 分母增长率 => 比值变大;分子增长率 < 分母增长率 => 比值变小〕｜⚠只看分子大小，不看分母变化

### 图表查找比较
- **图表查找四坑校验法**｜注意合计/总计行，避免将总计与分项混算｜⚠把合计行当普通分项参与排序

### 速算方法
- **截位直除法**｜选项差距小，通常截3位；选项首位相同且次位差小于等于首位，保留更多位｜⚠不看选项差距，截得过粗或过细
- **415份数法**｜根据R偏大偏小校正：估大则份数变大、估小则份数变小；增长率为负时要把本期对应份数作相应调整｜〔若R≈a/b，则A:X:B≈b:a:(a+b);X≈B×a/(a+b);A≈B×b/(a+b)〕｜⚠把R=a/b理解成X/B，而不是
- **假设分配法**｜根据R大小选择比例：R<20%时X≈BR；R≈25%时A:X≈4:1；R≈33%时A:X≈3:1；R≈50%时｜〔B = A + X;X = A×R；估算时先按B×R拆分再修正〕｜⚠分配树只分大数不校正小数
- **尾数-高位叠加-削峰填谷-乘法拆**｜乘法拆分：把百分数拆成100%-x%、50%+x%等常见形式｜〔平均数 = 基准值 + 偏离总和/项数;被减数-减数=(被减数-基准值)+(基准值-减数)〕｜⚠尾数法中借位处理错误
- **常用分数大小比较法**｜先判断分子、分母相对大小：分子大且分母小则该分数更大；分子小且分母大则更小｜〔同分母比分子；同分子比分母;分子分母一大一小：分子大且分母小的分数更大〕｜⚠PDF中明确标题是“常用分数比较

### 盐水类
- **十字交叉求分母之比**｜资料分析增长率中，R针对前期A，若代入增长率R，交叉出来的是A（基期）之比｜〔若混合值R位于A、B之间，则两部分分母之比 = |R-B| : |A-R|;盐水原式类比：(R-B)/(A-R) = 溶液A质量/溶液B质量〕｜⚠把十字交叉结果当分子之比
- **混合值不居中定性判断法**｜比较增长大小：部分1 > 整体 > 部分2 或相反｜〔混合值靠近量较大的部分值;增长大小比较：部分1 > 整体 > 部分2〕｜⚠误以为混合值一定在两个数正中间
- **已知2R/3R与量之比反求R法**｜人数相关题先把人均=总量/总人数，并将人均消费等转化为总量占比｜〔R = X/A;人均 = 总量/总人数〕｜⚠把人均相关题直接当人数之比
- **累计期与单月分段比较法**｜若只需判断超过与否，可比较第n月数值与累计平均或前段平均｜〔1-n月累计 = 1-(n-1)月累计 + 第n月;前段月均 = 1-(n-1)月累计/(n-1)〕｜⚠把累计值当单月值

### 特殊考点
- **拉动增长率/增量贡献率公式法**｜区分题目问法。若为拉动，找整体基期数据做分母；若为贡献率，找整体增量做分母｜〔拉动增长率 = 部分增量 / 整体基期;增量贡献率 = 部分增量 / 整体增量〕｜⚠将两者的分母混淆
- **两集合容斥边界判断法**｜问至少时，交集最小为a+b-100%或a+b-总量｜〔至少交集 = a + b - 100%（占比口径）;至少交集 = A + B - 总量（数量口径）;至多交集 = min(A,B)〕｜⚠问至多却用a+b-100%
- **容斥问题极值分析 (至少至多判断**｜求至多交集，直接选A和B中较小者｜〔至多交集 = min(A, B);至少交集 = A + B - 100%〕｜⚠至多和至少使用的公式记混

### 易错点
- **资料分析常见陷阱清单**｜核对问法：增长率、增长量、比重、比重差、平均数增长率是否混淆｜⚠百分点与百分数混淆

## 数量关系
### 数论与计算
- **常用代数公式与乘方尾数法**｜识别能否套平方差、完全平方、立方和差或提公因式｜〔a^2-b^2=(a+b)(a-b);(a+b)^2=a^2+2ab+b^2;a^3+b^3=(a+b)(a^2-ab+b^2)〕｜⚠指数整除4时不能记作余0参与尾数
- **倍数、整除与余数特性**｜用最大公约数处理重合间隔、植树重合等问题｜〔若a、b均能被x整除，则a+b、a-b也能被x整除;若x=ay/b且a/b为最简分数，x、y为整数，则x是a的倍数，y是b的倍数〕｜⚠把“能整除”误当成“只能等于”；

### 余数问题
- **余同取余、和同加和、差同减差**｜检查余数条件是否满足余同、和同或差同｜〔余同取余：x=M*n+r;和同加和：若除数+余数相同，x=M*n+和;差同减差：若除数-余数相同，x=M*n-差〕｜⚠未先判断口诀特征就硬套
- **LCM*n+x枚举法**｜从一个余数条件生成候选x｜〔x=M*n+最小满足条件的x0〕｜⚠把不满足特征的题强行套口诀

### 数列问题
- **等差、等比与递推数列公式**｜判断是等差、等比、递推或其他规律｜〔a_n=a_1+(n-1)d;S_n=n(a_1+a_n)/2=项数×平均数;a_n=a_1*q^(n-1)〕｜⚠等差求和忘记项数

### 数字推理
- **差商幂修正与分组观察法**｜变化较大时优先看倍数、乘法递推、幂次并修正｜〔常见基础：1非质非合；2是唯一偶质数；0的任何次方为0；任何数的0次方为1〕｜⚠急于套单一规律；多重数列未分组；
- **单调与趋势分析递推法**｜4. 变化较大：若倍数明显，直接做商或寻找乘法递推关系（如A3=A1×A2）；或者考虑次方运算（底数/指数变化｜⚠对1、0、2的质合性质及次方的特

## 言语理解-主旨意图
### 中心理解
- **主旨意图题结构优先总流程**｜用选项排除表检查：出处不对、片面、无中生有、偷换概念、绝对化、杂糅｜⚠看到首句主题词就直接选首句同义项

### 主旨概括
- **开门见山引出话题结构**｜若后文只是解释说明，则概括首句话题及后文共同核心｜⚠只选“话题是什么”，没有体现后文
- **观点—解释/论证结构解题法**｜把后文解释、例证、原因视为支撑材料｜⚠选解释材料中的具体危害
- **因果结构重点判断法**｜若因此推出观点或对策，选观点/对策｜⚠把结果当主旨
- **总分/分总结构总句优先法**｜判断分述内容是否围绕总句举例/展开｜⚠选分述中最显眼的细节

- **主旨概括整体覆盖法**｜确定主干信息：主体+核心观点/问题/原因/对策｜⚠选细节最熟悉的选项

### 意图判断
- **问题—对策结构解题法**｜选择对策的同义替换；没有对策选能体现问题的选项，但优先级低于对策｜⚠选问题项不选对策项
- **必要条件关系表对策法**｜判断必要条件指向哪一项措施或条件｜⚠把结果句当对策
- **尾句观点/对策重点法**｜若尾句重复或升华前文观点，优先选择尾句同义替换｜⚠所有题都机械看尾句

### 选项排除
- **出处不对排除法**｜判断出处功能：背景/例子/分析/让步/观点｜⚠选原文出现过但不是重点的句子

- **范围扩大、缩小与片面排除法**｜排除只说其一或主语范围错误的选项｜⚠把具体类选项当精确
- **绝对化选项排除法**｜若原文明确有最高级或比较关系，再保留｜⚠觉得选项语气强就像主旨
- **无中生有排除法**｜将选项拆成主体、动作、关系、结果｜⚠用生活常识补全原文没有的内容

- **杂糅拼凑选项排除法**｜检查这些信息在原文是否属于同一结构层级和同一逻辑关系｜⚠看到多个原文词就误以为概括全面
- **比较类/区别比较类选项验证法**｜若文段重点就是区别比较，则可选概括二者区别的选项｜⚠看到两个概念就选比较
- **太中性/未体现问题态度排除法**｜排除只介绍对象、过于平淡或主语过宽的选项｜⚠选看起来稳妥但态度缺失的选项
- **具体类选项验证法**｜若文段按时间或多方面列举具体方法，可保留具体类概括｜⚠文段只有原因或问题，却选“如何解

### 选项比较
- **有更具体选项时优选具体法**｜在不偏离原文的前提下优选更具体贴合项｜⚠把过度具体的局部项误认为更好


## 言语理解-语句表达与逻辑填空
### 综合流程
- **先判题型后结构化求解流程**｜先读题干形式：标题类看是否要求标题；下文类看是否问接下来讲什么；填入类看横线位置；排序类看句号编号；逻辑填空看｜⚠把标题题当普通主旨题但忽略标题可

### 标题填入
- **标题拟定主旨变形法**｜按主旨题方法先确定文段中心：总分、分总、问题—对策、并列、转折等｜⚠只抓最后一句造成片面
- **标题关键词主语一致法**｜若文段有观点/对策，标题需体现观点/对策而不是只写话题｜⚠选项表述很顺但主语换了
- **标题可读性与力度法**｜含引号或双关的标题只有在准确对应原文问题时才优先｜⚠为了有趣牺牲准确性
- **标题题干扰项排除法**｜标记选项来源：过去目的、现在作用、局部句、整体原因｜⚠标题看似精炼但只覆盖局部

### 下文推断
- **尾句承上启下看新信息法**｜若末句出现“过去没有/此前不足”，下文常接“现在突破/解决办法”｜⚠只看文段主题不看尾句新信息
- **总分话题结束反向续写法**｜若已讲完“有A”的情况，考虑下文可能讲“无A/另一类A”｜⚠误以为任何下文都看尾句
- **提出问题后接原因或对策法**｜若问题涉及责任主体，下文应继续围绕责任主体展开｜⚠把问题背景当下文重点
- **文末大对策后接具体做法法**｜下文一般不会重新论证问题，而是展开具体怎么做｜⚠回头选问题危害
- **已谈内容排除法**｜已完整解释的定义、危害、模式、背景通常不会作为下文主体｜⚠把“出现过”一律排除；真正要排除
- **下文推断干扰项排除法**｜保留最能承接尾句新信息或大对策的选项｜⚠只看题材相似，不看尾句关键词

### 语句填入
- **语句填入整体通篇法**｜先判断横线位置：段首多为总领，段中多为承上启下，段尾多为总结｜⚠只看横线后一两句导致片面
- **包含全篇关键词法**｜若前文说已有研究缺少A、局限B，则横线往往补“从A角度研究非B对象”｜⚠只命中一个关键词就选
- **话题一致与多主体概括法**｜确定后文共同话题，而不是每一句的局部对象｜⚠把“游戏发展”误当“游戏监管”
- **概括得当与具体承接法**｜横线句应是后文例子的上位概括，但不能过宽｜⚠概括过大如“开拓思路”
- **主语语法与指代一致法**｜检查横线后代词指代对象，横线句必须提供清晰先行词｜⚠选项本身正确但后文代词无所指
- **横线位置功能判断法**｜横线在开头：优先总领全文、引出话题或提出观点｜⚠只看横线后一侧

### 语句排序
- **语句排序整体结构套入法**｜判断材料可套入的结构：总分、分总、提出问题—分析—对策、时间顺序、转折对比｜⚠只靠语感排列
- **首句下定义与范围优先法**｜排除含“这/这些/其/该”等无先行词的句子作首句｜⚠把论证句放开头
- **尾句总结对策法**｜判断该句是否概括前文或提出最终做法｜⚠只看到“因此”就放尾，不检查前文
- **转折关系寻找上句法**｜上句应表达与转折后相反或形成对比的内容｜⚠只看到同一主题就捆绑，未验证转折
- **指示代词寻找上句法**｜在其他句子中找能被代词指代的先行内容｜⚠忽略代词导致句序断裂
- **尾首重复词相连法**｜找每句句尾的核心名词、观点名、理论名｜⚠所有同话题词都当尾首相连
- **时间轴与逻辑顺序法**｜若时间轴与逻辑结构冲突，以文段主线为准并重新验证｜⚠只按时间词机械排序而忽略指代
- **并列句组捆绑法**｜看并列标志词，如“也”通常不放并列组首句｜⚠把并列句拆散

### 逻辑填空
- **逻辑填空语境优先总流程**｜定位每个空前后的语境提示：解释、转折、递进、并列、因果、反向｜⚠先看选项不看语境
- **成语意思与适用语境法**｜排除色彩不符、语体不符、时间范围不符的成语｜⚠望文生义
- **实词不同字组词法**｜判断语境需要主动动作、被动接收、结果状态还是过程动作｜⚠把“采集、收集、搜集、汇集”混用
- **逻辑对应关系定位法**｜选词要能与提示句形成同义、反义、因果或程度对应｜⚠看到相同字就选
- **作者意图与对象特征法**｜跳出局部字面，判断作者想表达的总体意思｜⚠只按字面搭配选词
- **如果是你会怎么写法**｜排除只描述表情、泛泛夸奖或不贴合风险状态的词｜⚠被熟悉词吸引
- **转折前后反向定位法**｜转折前空格往往与转折后形成相反或对照｜⚠只看到‘但’不分析转折方向
- **递进程度加重法**｜第一空要与前文形成对应，第二空要体现进一步加重｜⚠忽略‘更不能’导致程度不升反降
- **并列同向与结构一致法**｜同向并列时，候选词应与旁边词语意义相近或同类｜⚠只看并列词不看语义方向
- **固定用法优先法**｜对多空题，固定搭配可先锁定一个空，再验证其他空｜⚠知道固定搭配但忽略语境
- **程度轻重匹配法**｜排除过轻、过重或不符合对象的问题词｜⚠词义方向对但程度不够
- **褒贬色彩匹配法**｜判断作者对对象的态度：肯定、否定、担忧、中性｜⚠把褒义词用于批评语境
- **主谓宾语法检查法**｜排除形容词误作动词、被动词误作主动词等语法错误｜⚠只看词义忽略词性
- **语体色彩和比喻一致法**｜正式语境优先书面表达，生活口语语境可选口语化｜⚠词义对但比喻不搭
- **政策语境与正向表达法**｜优先使用符合政策表达习惯的词，如严管与厚爱对应｜⚠不结合真实治理语境
- **常考实词差异积累卡**｜根据语境判断主观/客观、动作/结果、制度/行为、具体/抽象等差异｜⚠死记词表不看语境
- **近义词习惯搭配备查卡**｜将选项中的近义词逐一代入，判断是否符合日常习惯搭配｜⚠忽略横线前后的中心语，主观臆断词
- **望文生义防错卡**｜必要时标记为需要人工复核，不凭印象强选｜⚠按字面解释成语
- **关联词语义约束法**｜转折看反向，递进看加重，并列看同类，因果看原因结果｜⚠只认识关联词但不判断方向
- **强提示空优先突破法**｜提示强度排序：固定搭配 > 明确解释句 > 关联词反向/递进 > 对象特征｜⚠只验证第一个空


## 判断推理
### 逻辑论证
- **对比实验归因质疑与支持法**｜3. 分析质疑方式之一【另有他因】：必须保证“分组正确”。回到实验把水搅浑；若削弱，则指出两组对象除了原定变量｜⚠选项虽然指出了他因，但分组对象与

### 逻辑判断
- **归因论证削弱法**｜如果是“另有他因”，看选项是否提出了另一个更合理的解释（且选项不是题干已知事实）｜⚠把‘没有体现与往年对比’的无关项
- **对比实验评价法**｜若是削弱，寻找说明两组在其他方面也存在差异的选项（即没有控制好变量），或者寻找说明结果差异是由其他因素造成的选｜⚠只看结果变化，忽略了实验组和对照
- **一般质疑论证法**｜如果题干带有绝对化词语或逻辑关联词（如所有、只要就），使用对应的矛盾命题进行反驳（如A且非B）｜〔A → B 的矛盾是 A 且非 B;所有的矛盾是有些不〕｜⚠选项虽然反驳了论据，但是结论依然
- **支持与前提搭桥法**｜如果没有明显断点，把选项带入否定测试：如果选项不成立，结论是否必然不成立？如果是，则为必要条件/前提｜⚠在前提假设题中选择了‘加强但非必
- **比例论证反基数法**｜扫描选项，寻找带有总体数字、基数比例等能够充当‘分母’的选项｜〔实际比率 = 分子量 / 总基数(分母)〕｜⚠被题干中庞大的分子绝对量或片面比
- **解释矛盾合理化法**｜在选项中寻找能够串联双方、提供外部影响因素使其顺理成章的答案｜⚠只解释了单方面现象，没有回应为什
- **形式逻辑翻译及真假判定**｜对比选项的条件和结论，依据‘肯前肯后，否后否前’法则排除错误推导｜〔A → B <=> 非B → 非A;A → B 为假 <=> A 且 非B 为真〕｜⚠将‘只有...才’错误翻译为前推
- **三段论与归纳类比识别法**｜若题干或选项为类比推导，明确其论证力度极低，优先在选项中排查其他更严密的论证方式｜〔如果 A ⊆ B 且 x ∈ A，则 x ∈ B〕｜⚠用相同属性强行绑定集合关系（逆向
- **全变原则与常见矛盾关系**｜1. 识别命题中的逻辑关联词（且、或、所有、有些、可能、必然、->）｜〔A或B的否定 = 非A且非B;A且B的否定 = 非A或非B;A->B的矛盾 = A且非B〕｜⚠将'所有'的矛盾误认为'所有不'
- **假言命题翻译与逆否推理**｜3. 结合已知条件，应用逆否定理（肯前肯后，否后否前）得出结论｜〔如果A那么B => A->B;只有A才B => B->A;除非A否则不B => B->A〕｜⚠混淆充分条件和必要条件，导致箭头
- **等价推出与逆推法**｜3. 顺着箭头方向正推，或逆着箭头方向并取非（逆否）进行推理｜〔A->B->C = 非C->非B->非A〕｜⚠选择包含主观比较或原因分析的选项
- **真假推理之矛盾法**｜1. 找出题干中互为矛盾的两个命题（如 A 和 非A，所有 和 有些不）｜⚠找错矛盾关系
- **真假推理之假设法与代入法**｜2. 如果代入不便，选择一个命题进行假设（通常从最有可能导致冲突的命题开始，如复合命题）｜⚠假设后忘记验证是否产生矛盾
- **日常分析列表赋值与范畴画图法**｜【范畴分析】1. 根据'所有A是B'画大圈包小圈。2. 标记'有些'的交集，注意不确定边界画虚线或交界线上｜⚠范畴分析中将'有些'等同于确定的
- **“两个有的”秒杀法**｜将主语的人称变为‘所有’（如‘所有人都不不是党员’）｜⚠找错点名句
- **“两个所有”秒杀法**｜定位题干中具体点名的那一句话（如‘涛涛和龙龙是党员’）｜⚠将判断反转（与“两个有的”混淆）
- **三段论公式法：两个有的，一个所有**｜识别题干中两个含有“有些”或类似概念的命题，以及需要的补充条件｜⚠顺序颠倒
- **全对全错一对一错秒杀法**｜统计所有人说的话中，各个核心词汇（如车牌子，人名等）出现的次数｜⚠没有验证题目是否完全符合该特定模
- **每个人都只猜对了一半秒杀法**｜如果该句话得出后还有多个选项符合，利用“被分开必为假”原则排除：即若某结论为真，包含它反面或与它冲突的半句必然｜⚠统计次数错误
- **“只有xx说真话”点名法**｜他话中提到的人也不是“xx”，话中涉及的具体推断均取反（假）｜⚠将为假的内容错误取反
- **“只有一人说真话”找矛盾法**｜第二步：绕开矛盾，判定剩余的人所说的话全为假（如果只有一人说真话）｜⚠找错矛盾
- **分析推理“3+2”规律法**｜对于“不同”条件，寻找在多个不同对比中重复出现的人，直接锁定为答案｜⚠将“相同”错误归入数量为2的组
- **分析推理“4+3+2+1”秒杀法**｜找到数量为‘3’的条件，通过题干描述找到唯一一个不满足该条件的人（即不同的人）｜⚠推导队友逻辑关系时出错
- **大小比较：最大信息排除与大大则大**｜方法二（大大则大）：提取两组独立的大于关系（如 A > B, C > D）｜〔A > B, C > D => A+C > B+D〕｜⚠不等号方向看错
- **常用逻辑关系40组通式**｜识别题干中的逻辑关联词（如果...那么，只有...才，除非...否则，所有，有的，且，或）｜〔如果A，那么B = A -> B;只有A，才B = B -> A;除非A，否则B = -B -> A〕｜⚠除非A否则B翻译错方向（应为-B

### 类比推理
- **类比推理之造句与逻辑对应分析**｜1. 对题干词组进行造句，提取内在关系（如'苹果是水果的一种'）｜⚠将'组成关系'（轮胎与汽车）错认

### 图形推理
- **图推十五字口诀之定性与定量**｜3. 按照'点、线、面、角、素'的顺序逐一数数，寻找等差、等比、常数或对称规律｜⚠看到图形就盲目数点线面，不先做整
- **图推位置分析与元素换算叠加**｜2. 追踪特定元素的平移（上下左右）、旋转（顺/逆时针角度）或翻转（上下/左右翻折）｜〔第二个图形元素*2 = 第一个图形元素 + 第三个图形元素 (换算常用等差)〕｜⚠旋转和翻转混淆
- **图推三大类与六提示法**｜3. 敏感识别六提示：看到'日、田、五角星、圆相切'等立刻反应考查笔画数或切点/交点｜〔最少笔画数 = 奇点数 / 2 （奇点数非0）〕｜⚠奇点数找错，引出曲线的端点漏算
- **立体展开图三板斧与还原母图**｜第四步：使用第三板斧，相隔2格的面平移时，若为中心对称图形则直接平移，非中心对称则上下左右互换｜⚠平移两格时忘记非中心对称图形需要
- **常见几何体截面图总结**｜识别给定的立体几何体类型（如长方体、圆柱、圆锥）｜⚠将酒桶型误认为椭圆
- **命题形式与观察路径**｜若为分组分类题，先找共性再找差异；若第一眼看不出结论，去观察选项；勾出特殊或不同的图进行对比（必定是三分组）｜⚠九宫格未优先横向观察而陷入复杂斜
- **特征图思维法**｜若元素组成不同，优先考虑属性规律（对称性、曲直性、开闭性）或数量规律（点、线、角、面、素）｜⚠未判断元素组成相似度直接数数
- **拆分与对比思维**｜对比思维：对比选项（看哪些部分不变），对比题干（看相邻图形的差异）｜⚠整体观察无果时依然不愿拆分图形
- **平移规律**｜宫格型平移：中间不变优先顺逆时针走外圈；中间变化且有规律则内外圈分开看；中间变化无规律则整体看（行数量不变优先｜⚠忽视位置重合导致的黑块视觉减少
- **旋转与翻转规律**｜考察旋转：观察方向（顺/逆时针）和角度（恒定、递增/减）。注意是否为整体旋转与局部旋转结合，或旋转+元素加减｜⚠将翻转误判为旋转
- **遍历规律**｜数量遍历：每种样式的图形在行列中出现的次数是否相同，或每一组图是否都有一个固定相同的元素｜⚠未能识别出内外分开遍历
- **加减同异规律**｜注意验证变体：此类规律常与旋转和翻转结合考查，即先将图1或图2进行旋转/翻转后，再执行加减同异操作｜⚠未考虑基础图发生过旋转翻转再叠加
- **黑白运算规律**｜泛化提示：“具体图形”不一定必须是黑白块，也可能是其他特定图案（如星星、圆圈等）的叠加运算｜⚠默认黑+白=白+黑导致选错
- **对称性规律**｜考察对称轴与原图形的深层关系：①对称轴是否经过原图的特定点/线/面；②经过的点/线/面的数量是否有规律；③对称｜⚠只看对称性质未进一步看对称轴数量
- **开闭性规律**｜判断前提：当组成元素不同，曲直无规律时，考虑开闭性。提示特征包括完整图形有缺口、图形有阴影/粗线条、出现有封闭｜⚠将半开半闭图形误认为全封闭图形
- **曲直性规律**｜特殊线特征考查：横竖线明显、平行线组数（多线方向一边倒）、组成封闭面的线数量、贪吃蛇（一根线画到底，注意首尾变｜⚠曲线拐点判断错误导致数错曲线数量
- **一笔画与多笔画规律**｜计算奇点数：找到引出奇数（1,3,5...）条射线（含曲线）的点。注意端点处放射出1条线，也是奇点｜〔多笔画数 = 奇点数 / 2 (当奇点数 > 2时)〕｜⚠漏数或错数端点为奇点
- **点的数量规律**｜特别注意避坑：①纯考查“交点”个数时，一般不考虑端点（考出头点专项除外）；②按笔画数规律去数“奇点”时，必须考｜⚠数交点时错误把端点算入交点
- **立体截面图秒杀与穷举法**｜利用秒杀技巧：排除过于复杂或特殊的选项（如直角梯形、正五边形、圆柱的梯形、圆锥的四边形）｜⚠认为六面体可以截出直角三角形或钝
- **立体三视图还原与排除法**｜将立体图形在该方向上正投影，将曲面、斜面压平，注意面与面交界处的实线是否保留｜⚠将斜面投影时保留了立体感，未将其
- **立体拼合分层法与凹凸匹配**｜使用分层画图法或分层凑数法，将立体图形按高度分层（如1层、2层、3层），逐层填补空缺｜⚠方块数量计算错误


## 判断推理-图形推理
### 图推总流程
- **图推总流程卡片**｜再判断图形组成：元素组成相同优先位置规律；相似优先样式规律；不同优先属性规律、数量规律；特殊图形优先黑白块、汉｜⚠只看某一个图形特征就选项
- **图推分三轮处理策略**｜涂卡阶段再利用直觉回看难题，不因个别图推拖慢整体速度｜⚠连续盯一题超过合理时间
- **命题形式与读取顺序卡**｜立体类：从展开图、截面图、三视图、立体拼合分类进入专项｜⚠九宫格只横看不竖看
- **拆分思维与对比思维卡**｜位置拆分可看上下、内外、左右或横线分开规律｜⚠拆分维度过多导致自造规律
- **十五字口诀调用卡**｜屈：曲线直线；臣：对称；氏：相同相似图形；整：整体部分；风：封闭开放｜⚠背口诀但不判断组成

### 组成判断
- **组成相同优先看位置规律**｜若一致，优先看平移路径、旋转角度、翻转轴向｜⚠把相似图误判为相同图
- **组成相似优先看样式规律**｜检查相邻图是否存在加、减、去同、去异｜⚠只凭外观相似而忽略行列遍历
- **组成不同优先看属性与数量**｜出现明显提示图形时优先使用提示考点，如T点、出头、田字、五角星等｜⚠没有触发点就盲目数复杂数量
- **特殊图形优先专项路由**｜数字和字母先看对称、曲直、开闭、面数，再看本身大小、顺序或运算｜⚠把数字/字母只当普通图形，忽略本

### 位置规律
- **平移与移动路径法**｜确定移动主体：整体轮廓、小元素、空白、顶点/交点或线条｜⚠移动主体选错
- **旋转角度与方向法**｜将候选选项旋转回题干位置进行比对｜⚠把翻转后的镜像误当旋转
- **翻转轴与镜像识别法**｜判断两图是否横轴对称、竖轴对称或中心对称｜⚠对称图形本身看不出翻转，需找不对

### 样式规律
- **样式/数量/位置遍历法**｜检查缺失项是否为某一类元素、某一数量或某一位置｜⚠只看样式不看位置
- **加减同异与去同去异法**｜判断运算方式：直接相加、相减、去同存异、去异存同｜⚠未对齐图形就运算
- **黑白块同位置运算法**｜用一整行或一整列建立运算表，再用另一行/列验证｜⚠只比较黑块数量，不逐格运算

### 属性规律
- **对称性与对称轴法**｜必要时观察对称轴是否经过点、线、面或与图形关系平行/垂直｜⚠把近似对称当严格对称
- **开闭性判断法**｜若出现数字/字母，按其封闭面数量或开闭属性核对｜⚠把有阴影区域误当封闭空间
- **曲直性判断法**｜若整体属性无规律，分别数直线数、曲线数或曲直分开看｜⚠把弧线近似当直线

### 数量规律
- **一笔画与笔画数法**｜多笔画时通常按奇点数/2并结合分离部分相加｜⚠把端点当交点
- **点数量与交点类型法**｜先确定要数哪类点：交点、切点、出头点、内部交点、外框交点等｜⚠计数口径变化
- **线数量与线组关系法**｜确定数直线、曲线、线段总数还是特殊线组｜⚠把一条直线被交点分成多段后口径混
- **角数量与角类型法**｜只数小于180度的角，且通常需由相交线段形成｜⚠把180度直线当角
- **封闭面数量与面属性法**｜若总数无规律，再看某一类面：三角形面、四边形面、多边形面或相同形状面｜⚠把开放区域当面
- **元素种类与元素个数法**｜若多个图形可分为数部分，先确定相连/分离规则｜⚠把相连元素拆错

### 数量/属性规律
- **图形间相离相交关系法**｜判断图形之间是相离、相交于点、相交于线还是相交于面｜⚠把接触点当重叠面

### 数量/位置规律
- **功能元素标记位置法**｜判断标记所依附对象：交点、直线/曲线、最大/最小面、直角/锐角/钝角等｜⚠只看标记位置不看依附对象

### 特殊题型
- **黑白块综合判断法**｜再看数量：黑块数量是否相同，不同可看黑白差或直接数｜⚠黑数相同不先看平移
- **汉字图形规律法**｜必要时看特殊：拼音音调、拼音字母个数、笔画顺序起笔｜⚠只数笔画忽略结构
- **数字图形规律法**｜若出现数字组合，验证每一位或整体是否同规律｜⚠把题号当题干数字
- **字母图形规律法**｜最后看特殊：字母表顺序、字母本身算法｜⚠把选项A/B/C/D当题干字母

### 空间重构
- **六面体展开图总流程**｜先识别展开图结构，如1-4-1、2-3-1、2-2-2、0-3-3等｜⚠相对面同时出现未排除
- **相对面排除法**｜在展开图中找相对面：同行/同列隔一面常为相对面；一列/一行两端也可能为相对面｜⚠把相邻面误判为相对面
- **公共边验证法**｜一列/一行连着4个面时，最两侧的两条边可对应公共边｜⚠公共边找错导致方向反判
- **时针画边法**｜题干与选项对应面方向不一致则排除｜⚠起点不一致
- **立体截面图判断法**｜六面体可截出三角形、四边形、五边形、六边形，注意不能截出直角梯形、正五边形等限制｜⚠把圆锥斜截误判为四边形
- **立体三视图还原法**｜某些斜线或斜面可能被压平，注意透视压缩｜⚠把看不见的遮挡线画出来
- **积木题分层画图法**｜试拼时优先找特殊块或“占地大”的块，最好横跨所有层级｜⚠只看外观不数方块

### 选项验证
- **图推选项验证流程卡**｜优先排除违反硬规则的选项，如相对面同时出现、格位运算不一致、数量口径不一致｜⚠只用一个局部特征排除

### 易错点
- **图推常见误判点清单**｜防数量口径误判：点、线、角、面、素必须先定义计数对象｜⚠为了匹配答案临时换规则


## 判断推理-逻辑判断
### 逻辑判断
- **逻辑判断论证题总流程**｜第二步：划出论点，优先看因此、所以、由此、认为、说明、推测之后的内容；无明显标志时看作者最终态度｜⚠只看选项感觉合理但没有贴合题干主
- **论点-论据-论证方式拆解法**｜识别论证方式：是否存在因果归因、比例比较、样本推总体、对比实验、条件推出、解释矛盾｜⚠把背景信息当论点
- **演绎/归纳/类比推理识别法**｜类比推理：两个对象在某些方面相似，推出其他方面相似｜⚠用常识判断选项真假
- **加强/削弱力度比较通用规则**｜直接作用于论证关系的选项通常强于只作用于论据背景的选项｜⚠相关不等于有力度
- **常见无关选项排除法**｜检查选项是否只讲背景、只重复题干、只换了概念｜⚠把常识正确当作逻辑相关

### 结论推出
- **充分条件与必要条件识别法**｜识别 A 与 B：A→B 中 A 是充分条件，B 是必要条件｜〔A→B;¬B→¬A;必要条件位于箭头后件〕｜⚠把必要条件放到箭头前
- **如果/只要/所有都前推后翻译法**｜将如果、只要、若、所有都的前半句作为前件 A｜〔如果A那么B：A→B;只要A就B：A→B;所有A都B：A→B〕｜⚠把所有A都B翻译成B→A
- **只有A才B后推前翻译法**｜找到只有/必须/前提后的必要条件 A｜〔只有A才B：B→A;¬A→¬B〕｜⚠把A当充分条件
- **除非/否则翻译法**｜识别除非或必须后的条件 A｜〔除非A否则B：¬A→B;¬B→A〕｜⚠把除非A否则B误译为A→B
- **逆否命题等价验证法**｜识别逆命题 B→A 与否命题 ¬A→¬B，二者互相等价但不等价于原命题｜〔A→B ⇔ ¬B→¬A;¬A→¬B ⇔ B→A〕｜⚠肯定后件
- **或且关系否定法**｜要么A要么B同真同假均为假；或者A或者B同假为假｜〔¬(A∨B)=¬A∧¬B;¬(A∧B)=¬A∨¬B〕｜⚠只否定A不处理B
- **所有/有些/可能/必然关系转换法**｜所有A是B的矛盾通常对应有些A不是B；有些A是B的矛盾通常对应所有A不是B｜〔所有A是B ↔ 矛盾：有些A不是B;有些A是B ↔ 矛盾：所有A不是B〕｜⚠把有些理解成只有少数
- **结论推出翻译-匹配-排除法**｜先判断是否为翻译推理、真假分析、范畴分析或日常分析｜⚠把可能推出当必然推出
- **等价命题与选项替换法**｜若选项只是逆命题或否命题，不能当作等价｜〔A→B ⇔ ¬B→¬A〕｜⚠形式相似但方向相反

### 加强
- **支持题主体话题一致原则**｜若多个选项都相关，按是否直接补断点或直接增加事实比较力度｜⚠选项只谈背景但不服务论点
- **支持类断点搭桥法**｜寻找选项是否把 A 与 B 建立直接联系｜⚠把相关性当作桥梁
- **新增事实数据支持法**｜检查新增事实是否直接覆盖论点主体或关键范围｜⚠数据看似大但分母范围不一致
- **解释说明式支持法**｜看选项是否说明该因果关系的中间机制｜⚠机制解释到其他疾病但没解释题干结
- **必要条件式支持法**｜与普通事实支持比较时，必要条件通常更强｜⚠把充分条件当必要条件
- **排除替代路径加强法**｜与断点搭桥比较：本方法侧重堵漏洞，不一定连接新概念｜⚠排除的不是关键漏洞

### 前提假设
- **前提假设没它不行检验法**｜对每个选项做否定代入：如果否定该选项，结论是否无法成立｜〔前提判定：选没它不行，不选有它更好〕｜⚠把强支持误当必要前提
- **前提类断点搭桥法**｜寻找选项是否声明 A 能推出或指向 B｜⚠桥梁不够唯一但题干要求必要条件时
- **直接证据缺失补洞法**｜选项应补充为什么在当前情境下直接证据确实缺失或间接证据不可替代｜⚠把证据更多误作证据更重要
- **可行性前提法**｜判断如果该条件不存在，题干反应是否不会发生｜⚠把可能解释原因当成必要可行性

### 削弱
- **比例类论证分母校验法**｜正确选项常用比例或数字补充，说明绝对数比较不能推出比例结论｜〔率=分子/分母;只比分子不能推出率大小〕｜⚠只看死亡人数等绝对数
- **无论据有结论反驳结论法**｜排除仅重复题干、只解释题干或无关事实｜〔本质：A 与 ¬A〕｜⚠题干有论据时仍只反驳结论，可能力
- **肯定论据否定结论法**｜寻找选项是否补充事实说明即使 A 成立也不能推出 B｜〔削弱本质：A 且 ¬B〕｜⚠只反驳论据但不影响结论
- **A且非B削弱条件命题法**｜若选项只是另有原因但不构成反例，力度低于A且非B｜〔质疑 A→B：A∧¬B;质疑只有A才B：B∧¬A〕｜⚠条件方向翻译错误
- **归因论证识别与攻击总法**｜优先检查是否存在另有他因、因果倒置、否定此因、根/表原因、样本或实验问题｜⚠把相关关系当因果
- **另有他因削弱法**｜若 C 与A同时存在或更能解释结果，则削弱 A导致B｜〔A→B 被 C→B 削弱〕｜⚠C只是背景差异但不能解释结果
- **因果倒置削弱法**｜检查题干是否只证明相关，没有证明时间先后｜〔题干：A→B；削弱：B→A〕｜⚠忽略时间先后
- **否定此因削弱法**｜检查选项是否直接说明结果由另一个原因D造成｜⚠另一个原因不能解释主要结果
- **根本原因与表面原因转化法**｜若要削弱反对者B，可找A导致B，说明B只是中间机制或表层原因｜〔A→B→C 可说明B不是根本原因〕｜⚠只说明A能诱发疾病但没连接B
- **缺少对照组/对照不当检查法**｜若选项说明两组健康、心理等基础状况接近，可反驳对实验可信度的质疑｜⚠只比较结果不比较控制变量
- **样本无效削弱法**｜寻找选项是否指出大量总体成员未进入样本｜⚠只说最快离婚不是闪婚，不能代表总

### 解释说明
- **看似矛盾现象合理解释法**｜不要急于支持或削弱结论，而是寻找能同时容纳 A 和 B 的理由｜⚠只解释正式播出差但不解释试播好

### 加强削弱
- **实验初始状态一致性检查法**｜若要削弱实验结论，选项可指出实验前两组已存在关键差异｜⚠实验后差异不能证明实验前一致
- **构成对比实验变量控制法**｜加强选项应说明除A外条件一致；削弱选项应说明存在其他系统差异｜⚠只比较结果不控制其他条件

### 分析推理
- **真假分析矛盾-假设-代入法**｜找条件：根据题干真话/假话数量确定剩余话真假｜⚠没有先找矛盾就盲目假设
- **文氏图范畴分析法**｜根据所有/有些/没有画包含、相交或不相交关系｜⚠把有些区域画成全部
- **日常分析列表/代入/画图法**｜每代入一步都回到题干验证全部条件｜⚠不建立表格导致漏条件

### 评价论证
- **评价论证结构定位法**｜排除只补充背景、只重复题干、不能改变论证强弱的选项｜⚠把评价题直接当加强题


## 判断推理-定义判断与类比推理
### 定义判断
- **定义判断总体理解流程**｜先看问法，明确是“属于”还是“不属于”，不属于题最大陷阱是把符合定义的例子当答案｜⚠只见树木不见森林：把定义拆成过多
- **属于/不属于方向控制法**｜不属于题：先确认多个符合项可作为理解定义的例子，再寻找唯一不符合项｜⚠不属于题误选符合定义的典型项
- **抓住被定义词法**｜判断这些词为何被用作定义之名，推测其最核心特征｜⚠只看定义句中的局部词，不看定义名
- **定义判断三看选项设置法**｜看选项：不要因某一个表面特点就排除某项，要关注“被定义词”中不包含的信息｜⚠把不属于题看成属于题
- **定义关键词查找抓手法**｜若定义用有限枚举界定概念，可作为抓手；若是无限枚举，只能作为辅助理解｜⚠把普通修饰词当成强条件
- **主体限定排除法**｜主体不符合时直接排除；主体符合后再看对象和行为｜⚠忽略年龄、身份、组织类型等主体限
- **对象限定排除法**｜对象缺失、对象类型错误或对象关系不成立时排除｜⚠把兴趣对象误判为崇拜对象
- **特殊条件锁定法**｜圈出定义中的特殊要求，例如传统节日期间、工作学习过程中、借助他人等｜⚠把店庆、周年庆等商业节点误判为传
- **多定义一一对应法**｜不属于题中可借其他符合项理解目标定义，但不能把例子反推成新定义｜⚠只看到相似行为，未区分两个定义的
- **方式-目的-结果链检查法**｜从定义中提取方式、目的、结果三个位置｜⚠只看行为相似，忽略目的不一致
- **不符合定义项排除流程**｜第三轮比较剩余选项与被定义词核心含义的贴合度｜⚠排除理由不是定义依据，而是个人常
- **时间前后与变化对比法**｜若只描述某一时间点而缺失变化过程，谨慎排除｜⚠只看现在状态，忽略是否发生了定义
- **定义判断常见陷阱防错卡**｜检查是否把另一个定义类别误当成目标定义｜⚠只看关键词命中

### 类比推理
- **类比推理总体解题流程**｜二级辨析依次检查：感情色彩、程度轻重、词性、主动/被动、种属/组成、矛盾/反对、特指/泛指、关系方向｜⚠想太复杂，使用冷门知识
- **二级辨析总控法**｜补充检查词性、方向、关系强弱和对象类别｜⚠一级关系一致就匆忙选项
- **语义关系感情色彩与程度二级辨析法**｜若是近义/反义，继续比较感情色彩：褒义、贬义、中性｜⚠只看近义反义，不看褒贬色彩
- **对应关系主体数量核对法**｜先确认对应关系类型：功能、时间顺序、方式目的、职业场所、工具对象等｜⚠只要能造句就选择，忽略主体数量或
- **近义关系识别法**｜若多个选项近义，进一步看感情色彩、词性和语体是否一致｜⚠把相关关系误判为近义
- **反义关系识别法**｜若涉及非A即B，转入逻辑关系中的矛盾/反对二级辨析｜⚠把反义与逻辑矛盾混同
- **种属关系识别法**｜区分特指与泛指：苏格拉底-人类属于特指个体到类，公交车-汽车属于泛指类别到类｜⚠把轮胎-汽车误判为种属
- **组成关系识别法**｜确认A与B不是同类层级，而是部分与整体｜⚠种属与组成混淆是类比三难点之一
- **反对/矛盾二级辨析法**｜若非A即B、没有第三者，则为矛盾关系｜⚠把反对当矛盾，忽略第三者
- **交叉关系识别法**｜判断是否存在A∩B且A不完全属于B、B不完全属于A｜⚠把交叉误判为并列或种属
- **全同关系识别法**｜检查选项是否也是别称/简称/旧称/俗称关系｜⚠把近义误判为全同
- **引申义/象征义识别法**｜若多个选项可解释，比较是否同为人/物/抽象意义的代称｜⚠引入过深文学常识
- **功能关系识别法**｜检查选项是否也为物品-功能或功能-物品｜⚠把目的、结果、对象误判为功能
- **因果关系识别法**｜排除只是同时出现、先后发生、功能用途的选项｜⚠把时间顺序误判为因果
- **原材料-成品关系识别法**｜若方向相反，也需与题干方向一致才可选｜⚠把零件-整体误判为材料-成品
- **目的关系识别法**｜区别目的与实际结果：目的可能未必实现｜⚠把结果误判为目的
- **时间顺序关系识别法**｜若同时存在因果，比较题干是否强调流程顺序｜⚠把时间先后等同于因果
- **必要性对应识别法**｜判断题干是否表达必要条件或约束关系｜⚠把常见搭配误判为必要条件
- **造句法：工具-对象-场所对应**｜标注每个词在句子中的角色：地点、物品/工具、对象、动作等｜⚠造句过于牵强
- **拆词关系识别法**｜判断共同字在不同词中的含义是否相同或不同｜⚠只看字形重复，不看字义
- **词性一致检查法**｜标注题干各词词性：名词、动词、形容词等｜⚠只看词性一致而忽略内在关系
- **词语结构匹配法**｜判断题干短语结构：主谓、动宾、偏正等｜⚠把词语结构和逻辑对应关系混用
- **类比推理常见误判防错卡**｜检查是否把因果、功能、目的、时间顺序混淆｜⚠关系牵强也强行对应


## 图形推理
### 数量类
- **图形推理-数角法**｜2. 按规则数角：只数小于180°的内角；必须是直线与直线相交形成的角；角不重复数（但三角形数量可重复数）；封｜⚠数了大于或等于180度的角
- **图形推理-数面及面的特征**｜4. 如果仍然无规律，聚焦单个特殊面（特别是最大面或最小面）：观察其形状、面积比例、对称性，或与外边框的相似度｜⚠漏数或多数了面
- **图形推理-数素与部分数**｜3. 若单纯看数无规律，尝试不同种类元素间的数学运算，或者进行元素代换（图1和图2列方程求解代换比例）｜〔A*x + B*y = 常数/等差数列 (元素代换方程)〕｜⚠混淆'面'和'部分'的概念

### 结构类
- **图形推理-图形间关系(交点/交线**｜3. 如果是线相交，对比交线是长边还是短边（常用于分组分类），统计交线的数量，或看交线是直线还是曲线｜⚠只看整体形状，忽略了重叠部分的微

### 位置与结构类
- **图形推理-功能元素指向法**｜3. 提取被标记对象的特征（如最长边、锐角、最大面、相交面等）｜⚠把功能元素当成普通元素去数数量，

### 综合类
- **图形推理-黑白块规律**｜3. 分析黑白块的连通性：黑色块分成了几个部分？相连的黑块是一笔画吗？是点相连还是边相连？｜⚠数量相同时忘记看平移直接看运算

### 汉字类
- **图形推理-汉字考点全解**｜4. 细部统计：数总笔画数、交点数，或特定的笔画（如横、竖）。注意：笔画数必须严格按照标准汉字书写规范计算｜⚠笔画数数错（如将横折数成两笔）

### 符号与数字类
- **图形推理-数字考点综合**｜1. 判断数字是作为'图形'还是作为'数值'考察。如果是单排数字且字体有特色，倾向于图形属性｜⚠只按数值找规律而忽略了数字也可以
- **图形推理-英文字母考点**｜1. 观察字母形态，判断是否有明显的对称性规律或纯直线/纯曲线规律｜⚠忘记转换字母序列为数字来寻找数学

### 空间重构
- **图形推理-立体展开图解法(相对面**｜4. 遇到复杂图案，使用'顺时针画边法'：选定一个面为基准，按照1-2-3-4标边，核对选项中对应的相邻面是否｜⚠仅凭空间想象，容易记错面的方向
