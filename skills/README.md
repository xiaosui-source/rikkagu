## 🚀 Usage

- `SKILL.md` - The skill definition and instructions
- `agents/` - Agent configurations (e.g., `openai.yaml`)

## 📖 How to Use

1. Read the `SKILL.md` file to understand the skill's purpose
2. Follow the instructions in the skill guide
3. Use the agent configuration if needed
